# Travel Agency / Tourism Management System

## Project Overview
The Travel Agency / Tourism Management System helps customers explore travel packages, make bookings, manage payments, and allows administrators to manage packages and customer information.

## Objectives
- View and search travel packages.
- Register and log in customers.
- Book and cancel travel packages.
- Manage payment status.
- Allow administrators to add, update, and delete packages.
- Maintain customer and booking information.
- Test the main system functions.

## Main Modules
1. Customer Management
2. Travel Package Management
3. Package Search
4. Booking Management
5. Payment Management
6. Admin Dashboard
7. Testing

## Project Workflow
Problem Identification → Requirement Analysis → System Design → Development → Testing → Documentation
