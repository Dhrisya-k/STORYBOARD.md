# Customer Management

## Purpose
Customer Management handles registration, login, customer details and customer records.

## Registration
1. Customer opens registration.
2. Enters name, email, phone and password.
3. System validates input.
4. System creates the account.
5. Confirmation is displayed.

## Login
1. Customer enters credentials.
2. System checks the credentials.
3. Valid credentials allow access.
4. Invalid credentials show an error.

## Customer Profile
- Customer ID
- Name
- Email
- Phone
- Address
- Booking history

## Validation
- Required fields cannot be empty.
- Email should have a valid format.
- Password should follow security rules.
- Duplicate accounts should be handled.

## Expected Result
Customers can securely register, log in and maintain their basic information.
