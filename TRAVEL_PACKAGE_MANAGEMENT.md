# Travel Package Management

## Purpose
This module manages travel packages offered by the agency.

## Package Information
- Package ID
- Destination
- Package name
- Description
- Duration
- Price
- Available seats
- Travel date
- Status

## Administrator Operations

### Add Package
Enter valid package details and save the package.

### Update Package
Select a package, change its details and save.

### Delete Package
Select a package and confirm deletion.

## Customer Operations
Customers can view package details and select available packages.

## Validation
- Package ID must be unique.
- Destination and name should not be empty.
- Price should be positive.
- Availability should not be negative.

## Expected Result
Customers see current packages and administrators can maintain package information.
